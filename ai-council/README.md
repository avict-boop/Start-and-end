# Совет нейросетей (AI Council)

Несколько моделей (Claude, ChatGPT, Gemini, Kimi, DeepSeek и др.) решают одну задачу, как совет экспертов:
предлагают варианты вслепую, анонимно критикуют чужие, дорабатывают свои, голосуют, а председатель
выносит итоговое решение с обоснованием и особыми мнениями. Все модели подключаются через
[OpenRouter](https://openrouter.ai), поэтому нужен **один ключ**.

## Как проходит заседание

```
[0] Постановка   председатель уточняет вопрос и задаёт 3–5 критериев (или ваши: --criteria)
[1] Предложения  все участники параллельно и вслепую предлагают свой вариант
[2] Анонимизация варианты перемешиваются и получают метки A, B, C…
[3] Критика      каждый оценивает чужие варианты по критериям (1–10), сильные/слабые стороны
[4] Доработка    каждый видит критику своего варианта и улучшает его      ← [3–4] × N раундов
[5] Голосование  ранжирование чужих вариантов, нормированный подсчёт Борда
[6] Вердикт      председатель: победитель, финальный ответ, почему, особые мнения, риски
```

Защита от типичных проблем:
- **Самопредпочтение.** Варианты анонимны, за свой вариант голосовать и оценивать его нельзя.
- **Конформизм.** Первый раунд проходит вслепую, а один участник может быть «адвокатом дьявола».
- **Сбои провайдеров.** Упавший участник выбывает из этапа, заседание идёт дальше, пока есть кворум.
  Если не ответил председатель, итог подводится по голосованию.
- **Кривой JSON.** Ответы проверяются по схеме (pydantic). При ошибке модель получает подсказку и отвечает повторно.
- **Расходы.** Перед стартом программа проверяет, что все модели есть на OpenRouter (и подсказывает похожие id),
  и показывает план вызовов с оценкой стоимости по актуальным ценам. Во время заседания действует жёсткий лимит
  `max_cost_usd`, учитывается фактическая стоимость, которую возвращает OpenRouter.

### Режимы

| Режим | Что происходит | Когда использовать |
|---|---|---|
| `quick` | предложения → голосование → вердикт | быстро и дёшево |
| `debate` (по умолчанию) | + критика и доработка, `--rounds N` | важные решения |
| `evaluate` | вы даёте готовые варианты, совет их оценивает и выбирает | выбор из известных вариантов |

## Установка

```bash
cd ai-council
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env    # и вставьте ключ с https://openrouter.ai/keys
```

Ключ нужен один: `OPENROUTER_API_KEY`. На счёт OpenRouter надо положить немного денег.
Одно заседание из 5 моделей в режиме `debate` обычно стоит от нескольких центов до ~$0.5,
в зависимости от моделей и длины ответов.

## Веб-интерфейс

```bash
python -m council web          # затем откройте http://127.0.0.1:8000
```

В браузере можно:
- задать вопрос, выбрать режим, участников, председателя, адвоката дьявола и лимит;
- оценить стоимость заранее (проверяются и названия моделей);
- смотреть заседание вживую: этапы, кто из моделей «думает», варианты, тепловую матрицу оценок,
  бюллетени, итог голосования, вердикт и текущие расходы;
- скрыть авторов вариантов до вердикта, чтобы самому не поддаваться предвзятости;
- остановить заседание, открыть прошлые заседания из истории, скачать отчёт `.md`.

Без ключа доступен демо-режим. Сервер по умолчанию слушает только `127.0.0.1`: пароля нет,
поэтому не открывайте его в сеть (`--host 0.0.0.0`), иначе любой сможет тратить ваш баланс.

## Командная строка

```bash
# Пробный прогон без ключа и без затрат (фейковые ответы):
python -m council ask "Какой стек выбрать для MVP интернет-магазина?" --mock

# Проверить модели и оценить стоимость, ничего не запуская (ключ не нужен)
python -m council ask "Какой стек выбрать для MVP интернет-магазина?" --dry-run

# Полноценное заседание (перед стартом покажет план и стоимость и спросит подтверждение; -y — без вопроса)
python -m council ask "Какой стек выбрать для MVP интернет-магазина?"

# Быстрый режим, свои критерии, лимит бюджета
python -m council ask "Как назвать кофейню у университета?" --mode quick --criteria "запоминаемость,уникальность,звучание" --budget 0.3

# Два раунда дебатов, контекст из файла
python -m council ask "Стоит ли переводить сервис на микросервисы?" --rounds 2 --context-file context.md

# Выбор из готовых вариантов (в файле варианты разделены строкой ---)
python -m council ask "Какую БД выбрать для аналитики?" --option "PostgreSQL" --option "ClickHouse" --option "BigQuery"
python -m council ask "Какой бизнес-план лучше?" --options-file plans.txt

# Только часть участников
python -m council ask "..." --only claude,gemini,deepseek

# Найти точные id моделей на OpenRouter
python -m council models kimi
```

Результаты сохраняются в `runs/`:
- `*.md` — отчёт: решение, таблица голосования, бюллетени, все варианты, критика, расходы по участникам;
- `*.json` — полная стенограмма, включая сырые ответы каждой модели.

## Настройка участников

Участники задаются в файле `config.yaml`. Чтобы подключить дополнительную модель, включите её (`enabled: true`) или добавьте свою:

```yaml
members:
  - name: grok
    model: x-ai/grok-4
    enabled: true
    temperature: 0.9   # необязательно: свои параметры для участника
```

Уже подготовлены, но выключены: **Grok** (xAI), **Qwen** (Alibaba), **Mistral**, **Llama** (Meta),
**Perplexity Sonar** (с поиском в интернете, подходит как фактчекер). id моделей на OpenRouter
периодически меняются, актуальные можно посмотреть командой `python -m council models <поиск>`.

## Структура

```
council/
  client.py    клиент OpenRouter: ретраи, таймауты, учёт стоимости
  config.py    конфиг (YAML) и .env
  schemas.py   pydantic-схемы ответов на каждом этапе
  prompts.py   промпты для ролей и этапов
  voting.py    разбор JSON, анонимизация, проверка ответов, подсчёт Борда
  session.py   оркестратор заседания (этапы 0–6, кворум, бюджет)
  report.py    отчёт Markdown и стенограмма JSON
  estimate.py  проверка моделей и оценка стоимости до запуска
  mock.py      фейковый клиент для --mock и тестов
  cli.py       командная строка
  web/         веб-интерфейс: FastAPI + SSE (app.py) и страница без сборки (static/)
tests/         pytest
```

Тесты: `pip install pytest && python -m pytest`.
