# Пакет для заседания «Третья полная проверка Совета нейросетей»

Третья проверка: совет проверяет всё приложение — как внедрены рекомендации первого аудита и исправления по независимому мнению эксперта, — ищет новые проблемы, разбирает все параметры и режимы и даёт следующие рекомендации и план пилота.

| Файл | Что это | Куда |
|---|---|---|
| `00-tz.md` | ТЗ — сам вопрос совету | весь текст скопировать в поле вопроса |
| `01-logika-chast-1.md` | логика совета, часть 1 (из `docs/logic.md`) | вложение |
| `02-logika-chast-2-i-nastroyki.md` | логика, часть 2, и весь `config.yaml` | вложение |
| `03-zaprosy-k-modelyam.txt` | дословные запросы к моделям во всех режимах | вложение |
| `04-nablyudeniya-i-ogranicheniya.md` | цели, реальные данные, что сделано не полностью, слабые места, ограничения, вопросы; код проверок ответов | вложение |

Все четыре вложения вместе — около 149 500 символов — почти весь лимит программы: 150 000 на все документы и 60 000 на один. Другие файлы к этому заседанию лучше не прикладывать, иначе текст обрежется.

## Как запустить

1. **Скачайте файлы.** На GitHub откройте папку `ai-council/docs/audit-tz` в ветке `claude/multi-ai-comparison-tool-50nc5z`. У каждого файла есть кнопка «Download raw file».
2. **Создайте вопрос.** На сайте совета — «Новый». Вставьте в поле вопроса весь текст `00-tz.md`.
3. **Приложите файлы.** «Файлы» → `01`, `02`, `03` и `04`.
4. **Режим** — «Подробное обсуждение», 1 раунд:
   - нужны глубокий разбор и готовые тексты запросов, а не таблица фактов;
   - «Исследование» здесь хуже подходит: вопросы аудита — про логику и решения, их не проверить поиском.
5. **Параметры:**
   - проверка фактов **включена** — она проверит утверждения о возможностях OpenRouter и моделей;
   - компактные варианты **выключены**;
   - председатель без своего варианта — как обычно.
6. **Состав.** Можно нажать «✨ Подобрать состав» и снять галочки с лишнего. Председателю нужен большой предел ответа: итог будет длинным.
7. **Бюджет.** Посмотрите оценку стоимости перед стартом. Каждая модель читает вложения (около 40 000 токенов) на нескольких этапах. Ориентир — **$6–12**, это моя прикидка, а не расчёт. Поставьте лимит $15. Если не хватит, заседание встанет на паузу и продолжится без повторной оплаты. Учтите лимит ключа OpenRouter ($300).

## Как обновить пакет после изменений программы

```
python docs/audit-tz/build.py
```

Скрипт пересобирает `01`–`03` из `docs/logic.md`, `config.yaml` и кода запросов, дописывает к `04` код проверок ответов и проверяет лимиты вложений. Файл `00` и основной текст `04` пишутся вручную.
