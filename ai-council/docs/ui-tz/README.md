# Пакет для заседания «Удобный и современный интерфейс»

| Файл | Что это | Куда |
|---|---|---|
| `00-tz.md` | ТЗ — сам вопрос совету | весь текст в поле вопроса |
| `01-opisanie-interfeisa.md` | экраны, сценарии, компоненты, ограничения, история жалоб | вложение |
| `02-razmetka-i-stili.md` | разметка страницы и дизайн-токены (цвета, шрифт) | вложение |
| `screens/s01…s08.png` | 8 скриншотов: 6 экранов компьютера, 2 экрана телефона (один в тёмной теме) | вложения |

Всего 10 вложений — это предел программы для одного вопроса. Скриншоты сняты размером в экран, поэтому после
уменьшения до 1600 пикселей текст на них читается. Сняты в демо-режиме: интерфейс настоящий, тексты ответов
условные.

## Как запустить

1. **Скачайте файлы.** На GitHub откройте папку `ai-council/docs/ui-tz` и папку `screens` в ней, ветка
   `claude/multi-ai-comparison-tool-50nc5z`. Скачайте каждый файл: «Download raw file».
2. **Создайте вопрос.** На сайте совета нажмите «Новый» и вставьте в поле вопроса весь текст `00-tz.md`.
3. **Приложите файлы.** «Файлы» → `01`, `02` и все 8 картинок.
4. **Режим** — «Подробное обсуждение», 1 раунд. Проверку фактов можно выключить: вопрос про дизайн, а не про
   факты. Компактные варианты выключите.
5. **Состав.** Важно, чтобы модели **видели картинки**: на карточках моделей в «Настройках» это метка «видит
   картинки». Модели без зрения получат текстовое описание скриншотов от зрячей модели — это хуже для разбора
   дизайна. Можно нажать «✨ Подобрать состав» и оставить зрячие модели. Председателю нужен большой предел ответа.
6. **Бюджет.** Посмотрите оценку перед стартом. Картинки — около 1100 токенов каждая на каждом этапе, где
   модели видят вложения, текст — около 15 000 токенов. Ориентир — $3–8; это моя прикидка, не расчёт. Поставьте
   лимит $10.

## Как обновить пакет после изменений интерфейса

1. Переснимите скриншоты в демо-режиме: те же 8 экранов, размер окна 1280×860, телефон — iPhone 13.
2. Пересоберите вложение `02` и проверьте лимиты:

   ```
   python docs/ui-tz/build.py
   ```

   Скрипт пересобирает `02` из `index.html` и `style.css`. Файлы `00` и `01` пишутся вручную.
