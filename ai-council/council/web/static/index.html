    Несколько нейросетей решают вашу задачу как совет экспертов

    1. Предложения. Каждая модель вслепую предлагает свой вариант.
    2. Критика. Варианты анонимны (A, B, C…), модели оценивают чужие по критериям.
    3. Доработка. Каждая модель улучшает свой вариант с учётом критики.
    4. Голосование. Ранжирование чужих вариантов, подсчёт по Борда.
    5. Вердикт. Председатель сводит лучшее в итоговое решение.
