# Анализатор состава БАД

Программа проверяет, соответствует ли состав и маркировка биологически активной добавки (БАД) требованиям законодательства РФ и ЕАЭС.

> ⚠️ Результат носит справочный характер и **не заменяет** экспертизу и государственную регистрацию (СГР).
> Справочники в `bad_checker/data/` — **стартовый набор**. Перед практическим применением их нужно сверить с актуальными редакциями нормативных актов.

## Что проверяется

| Проверка | Нормативная база | Справочник |
|---|---|---|
| Запрещённые растения, вещества, гормоны, лекарственные субстанции | ТР ТС 021/2011, Приложение 7; 3-ФЗ; ПП РФ № 964 | `data/prohibited.json` |
| Суточная доза витаминов, минералов и других веществ не выше ВДУ; доля от адекватного уровня (АУП) | Единые сан.-эпид. требования (Решение Комиссии ТС № 299), гл. II, разд. 1, прил. 5 | `data/nutrients.json` |
| Неразрешённые пищевые добавки (E-коды) | ТР ТС 029/2012 | `data/additives.json` |
| Обязательные элементы маркировки: «БАД к пище», «Не является лекарственным средством», противопоказания, СГР и др. | ТР ТС 022/2011, ст. 4.1, 4.4 | `analyzer.py` |
| Заявления о лечебных свойствах | ТР ТС 022/2011; 38-ФЗ «О рекламе», ст. 25 | `analyzer.py` |
| Номер СГР: формат, дата выдачи, код вида продукции | ТР ТС 021/2011, ст. 24 | `sgr.py` |

Что ещё умеет программа:
- переводит единицы: г, мг, мкг и МЕ (для витаминов A, D, E);
- пересчитывает дозу на сутки: количество на 1 таблетку × число таблеток в день;
- предупреждает, если для минерала указана масса соли (например, «магния цитрат»), а не элемента;
- распознаёт русские и латинские названия с учётом падежных окончаний («эфедры», *Ephedra sinica*).

## Установка

Нужен Python 3.10 или новее. Ядро и веб-интерфейс работают без сторонних библиотек.

Для распознавания фото этикеток нужен Tesseract с русским языком:

```bash
sudo apt-get install -y tesseract-ocr tesseract-ocr-rus
```

```bash
pip install -r requirements.txt
```

На macOS: `brew install tesseract tesseract-lang`. На Windows — установщик UB Mannheim Tesseract с русским языковым пакетом.

## Веб-интерфейс

```bash
python -m bad_checker.web
```

Откройте http://127.0.0.1:8000 в браузере. Там можно вставить состав и текст этикетки или загрузить фото этикетки. Результат выводится с таблицей доз и фильтром замечаний, отчёт можно скачать в Markdown.

Сервер также принимает JSON-запросы: `POST /api/analyze` с полями `name`, `composition_text`, `label_text`, `units_per_day`, `amounts_per_unit` и `image` (data URL). Проверить доступность OCR: `GET /api/health`.

## Командная строка

```bash
python -m bad_checker examples/multivitamin_ok.json
```

```bash
python -m bad_checker examples/fatburner_bad.txt --per-day 2
```

```bash
python -m bad_checker examples/multivitamin_ok.json --format md -o report.md
```

Можно передать фото этикетки — текст будет распознан:

```bash
python -m bad_checker examples/label_photo.png
```

Форматы отчёта: `text`, `md`, `json`. Коды возврата: `0` — соответствует, `1` — есть предупреждения, `2` — есть нарушения.

## Входные данные

**JSON** (рекомендуется):

```json
{
  "name": "Название продукта",
  "daily_dose": {"units_per_day": 2, "unit_name": "капсула", "amounts_per_unit": true},
  "ingredients": [
    {"name": "Витамин D3 (холекальциферол)", "amount": 1000, "unit": "МЕ"},
    "Магний (в пересчете на магний) 100 мг",
    "Микрокристаллическая целлюлоза"
  ],
  "label_text": "Полный текст этикетки…"
}
```

**Текст** (`.txt`) или **фото** (`.png`, `.jpg`): если в тексте есть заголовок «Состав:», компонентами считаются строки после него — до «Рекомендаций», «Противопоказаний», «Срока годности» и т. п. Без заголовка компонентом считается каждая строка (или часть через `;`). Весь текст дополнительно проверяется как текст этикетки.

## Проверка СГР

Программа находит на этикетке номер свидетельства о госрегистрации (например, `RU.77.99.11.003.R.001234.05.24`). Она проверяет формат номера, месяц и год выдачи, а также код вида продукции (для БАД — `11`).

Действует ли свидетельство, нужно проверять вручную в Едином реестре ЕАЭС (portal.eaeunion.org): стабильного публичного API у реестра нет.

## Использование из Python

```python
from bad_checker import analyze, product_from_dict
from bad_checker.report import to_json

report = analyze(product_from_dict({...}))
print(report.verdict)
print(to_json(report))
```

## Как дополнить базу

Справочники — это обычные JSON-файлы; код менять не нужно. Например, чтобы добавить запрещённое растение, допишите запись в `data/prohibited.json`:

```json
{"id": "...", "names": ["русское название"], "latin": ["Genus species"],
 "category": "растение", "basis": "ТР ТС 021/2011, прил. 7", "note": "..."}
```

Поле `"severity": "warning"` помечает ограниченный компонент: продукт с ним получает статус «требует проверки», а не «нарушение».
